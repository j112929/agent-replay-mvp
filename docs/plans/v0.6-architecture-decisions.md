# v0.6 architecture decisions

1. Reuse BenchmarkRunner, PlanningAgent and execution authorization. The research
   planner supplies the existing session contract; no parallel agent runtime.
2. Reuse the WorldModel.predict interface. Large bounded hypothetical datasets
   belong in associated versioned files, not relaxed online trajectory limits.
3. Probability semantics are explicit: task/action success, model confidence,
   epistemic/aleatoric diagnostics are separate. Self-reported confidence remains
   uncalibrated. Missing labels remain missing; simulation outcomes are not labels.
4. Fit Platt/PAVA on declared training groups only. Evaluation groups, scenario
   provenance, task versions and label timing must be validated. New calibration
   artifacts record fitting hashes and versions; no online base-model updates.
5. CVaR is the mean loss of the worst (1-alpha) probability mass, including a
   fractional boundary sample. Repeated task seeds use cluster bootstrap. Effects
   with insufficient coverage/uncertainty remain inconclusive; screening comparisons
   use Holm correction where hypothesis p-values are reported.
6. Only bundled synthetic environments are executable through CLI. Public UI is
   an aggregate artifact reader; no tool or GPU service and no new cloud resource.
7. Preserve schemas and default behavior. Optional probabilistic release policy
   composes with current release gate, rather than bypassing existing checks.
