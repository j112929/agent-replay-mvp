# v0.5 validation record

This record separates implementation mechanics from prediction/reliability quality.
All data used here is synthetic, independent of employer systems or data.

| Milestone | Concrete files | Validation and limits |
| --- | --- | --- |
| 1: foundation | world_model/interfaces.py, refund.py, dataset.py, evaluation.py | Real Refund doubles match deterministic oracle, legacy capture conversion is explicit, grouped/authorized dataset and independent prediction tests |
| 2: planning | planning/contracts.py, core.py, world_model/providers.py | Shadow parity, schema-validated sampled candidates, bounded H×N existing planner and same deterministic execution authorization |
| 3: closed loop | planning/core.py, evaluation.py, dist/planning.js | Actual stale-context error triggers bounded replan; zero correction budget stops; one refund max; existing replay retains correction records |
| 4: model improvement | world_model/training.py, local.py, registry.py | Actual CPU categorical fit; actual tiny CPU LoRA gradients/validation/checkpoint/reload; held-out and real shadow promotion/rollback test; no online training |
| 5: benchmark/release | world_model/experiments.py, publish.py, CLI, world-model.html/js, workflows | Matched baseline/shadow/active/correcting and ablations, existing reports/gates, static public aggregate artifact; no production deployment |

The original 131-test baseline plus 13 new unit/integration tests passes locally.
12 web unit tests, 13 SaaS tests and 2 browser flows include the imported planning/evaluation pages.
Optional-library CPU LoRA smoke runs separately; GPU/NCCL/vLLM and useful open-weight
forecast quality are not established by this evidence. Current test command outputs
and full generated artifacts are reproducible through the workflows.

The CPU experiment uses 20 matched Refund tasks. Baseline and shadow each pass 8;
active passes 16; active+self-correction passes 20. The additional safe-rule policy without any world model also passes 16; therefore this benchmark does not establish incremental world-model reliability gains. H=1/3/5 and removed risk/uncertainty
penalties have identical pass counts on this simple oracle environment. This is not
evidence that longer imagination is universally useful. Failed outcomes and added
cost remain present; the strict example cost/tool gate blocks the correcting version.

Supervised next-observation accuracy is measured on held-out scenario families,
not generated hypotheses. The default categorical model has limited feature support
and may fail shadow planning on unseen alternate actions. Offline prediction accuracy
alone does not establish active-agent quality; promotion refuses missing evidence.

## Remaining risk register

- Synthetic deterministic business rules do not establish real-world or stochastic-agent improvement.
- Correct family/provenance grouping is required; automatic semantic leakage detection is absent.
- Oracle confidence is deterministic by construction; learned frequencies/LLM confidence are uncalibrated.
- CPU LoRA validates mechanics only; tiny model output may be invalid and is rejected.
- Local HF code is trusted SDK inference; async cancellation cannot interrupt an arbitrary tensor operation.
- SFT optimizer resume is unsupported; existing RL checkpoint resume is a separate feature.
- Cost estimates require explicit measured pricing; missing cost blocks model promotion.
- Static public reports are aggregate-only; private datasets/fixtures/checkpoints must stay outside web roots.
- Registry references are local single-operator artifacts, not a production deployment service.

Rollback: disable planning or use mode=disabled, restore a known package and retain
immutable evidence; no SQL downgrade needed. Registry rollback only restores an
approved local reference. Existing host replay execution remains denied.

No incremental world-model success gain over the safe-rule controller is established.
Correction recovers four injected stale-context cases, with 100% recovery on these
four synthetic attempts, at higher cost/calls. The strict 25% cost/tool policy gate
returns FAIL. These USD values exclude unpriced CPU compute; no provider tokens or
payments were used. Source artifacts record all scoring coefficients and task IDs.

Independent held-out next-observation evaluation uses 13 transitions: both oracle
and categorical model exact-match accuracy are 12/13 (92.3%). This does not establish
an improvement from learning. Positive-only eligible terminal labels cannot establish
ROC/PR discrimination or general calibration; report class counts and unavailable
metrics rather than interpreting a zero Brier score as certification.

Tiny CPU LoRA was executed with PyTorch 2.14.0+cpu, Transformers 5.17.0 and PEFT 0.21.2.
Real adapter gradients, validation loss, sealed checkpoint and local predictor load
passed. Generated prediction quality, large/Qwen checkpoints, GPU and distributed
world-model inference remain unvalidated. Existing RL/DDP/Ray acceptance stays in
its separate unchanged workflow.
