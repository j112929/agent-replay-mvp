# v0.5.0 release candidate

Incremental Model-Based Agent Planning and Evaluation Platform. Code version bump
is not a published package release, production deployment or reliability guarantee.

- World model adapter, deterministic Refund oracle, independent structured prediction evaluation.
- Explicitly authorized/versioned JSONL training datasets with grouped held-out provenance.
- Shadow/active planning, bounded self-correction, resource-key irreversible-action protection.
- Actual CPU supervised categorical fit; optional local HF SFT/LoRA and sealed validation checkpoints.
- Paired baseline/shadow/active/correcting and horizon/risk/uncertainty ablations, existing reports/gates.
- Offline registry with paired prediction baseline, real shadow evidence and rollback.
- Static import-only planning/evaluation UI; aggregate public artifacts exclude raw private data.

Compatibility: existing commands, enabled planning config field order, trajectory v2,
benchmark store and distributed rollout protocols remain. New v0.5 presets are
explicitly disabled/shadow by default. Executable host replay remains denied.
No SQL migration or required GPU/model dependency. Optional-library validation and
prediction quality are separate claims; see [guide](v0.5-world-model.md).
