# v0.6.0 research preview

Added optional probabilistic reliability experiments on the existing platform:
strict pre-outcome forecasts, held-out Platt/PAVA calibration, risk-aware Monte
Carlo planning, four baseline planners plus uncertainty-CVaR, separated horizon
protocols, observation-triggered replanning, grouped comparisons and three Labs.

Existing BenchmarkRunner, PlanningAgent, trajectory v2, recorded replay and release
gates are reused. No required dependency, SQL migration or new hosted executor.
Unknown/missing/censored evidence remains INCONCLUSIVE. Production replay remains
data-only; imagined actions have no execution capability.

Capture now finalizes interrupted child spans and records current SDK provenance.
This is an intentional correction for incomplete captures exposed by Python 3.14.
Existing completed trace and command contracts remain compatible.

See [actual validation, measurements and limitations](v0.6-validation-report.md),
[reproduction guide](v0.6-probabilistic-research.md), and
[repository audit](v0.6-repository-audit.md). Observed synthetic differences do not
establish production benefit. The H=32 uncertainty strategy hit record budgets;
those outcomes stay censored and are excluded from success curves.

No production deployment, paid provider/GPU run, online model update or live
billing activation is included. This preview is delivered as a draft PR on v0.5.
